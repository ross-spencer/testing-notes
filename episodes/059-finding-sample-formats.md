# Finding Format Examples {#finding-format-examples}

The more Samples you can find, the more precise the signatures can be.

File format examples can can found on:

* Search Engines, e.g. `<search term> filetype:pdf`
* Just solve it: File Formats Wiki
* Internet Archive
* eLearning Sites
* Compiled Corpuses.
* Make your own\!
