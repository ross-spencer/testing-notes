## Useful tools

### Windows

* [HxD](https://mh-nexus.de/en/hxd/) hex Editor
* [7-zip](https://www.7-zip.org/) ZIP/OLE Extractor/viewer
* [Notepad++](https://notepad-plus-plus.org/) XML/Text/File viewer

### Mac

* [hexfiend](https://hexfiend.com/) hex Editor
* [p7zip](https://formulae.brew.sh/formula/p7zip) 7zip for Mac
* [bbedit](https://www.barebones.com/products/bbedit/) XML/Text/File viewer

### Linux

* [hexyl](https://github.com/sharkdp/hexyl) hex Editor

### Web based

* [werewolv](https://web.imhex.werwolv.net/) hex Editor
* [hexed.it](https://hexed.it/) hex Editor

### Python

* [oletools](https://github.com/decalage2/oletools) OLE tools

## PRONOM Drop-in

The PRONOM team also hosts regular open drop-in sessions:

* Every two weeks on Thursday at 4:00pm (UK) / 11:00am (ET)

Further information on dates and joining instructions can be found on the
